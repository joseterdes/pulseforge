# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report privately via GitHub instead: go to the repository's **Security** tab, choose **Report a vulnerability**, and include:
- what's affected and how to reproduce it
- the impact you expect
- any suggested fix.

PulseForge is run by a single maintainer, so responses are best-effort. You should get an acknowledgement within 7 days. Please give us a reasonable time to fix the issue before disclosing it publicly.

## Scope

Everything in this repository is in scope. Secrets accidentally committed to the history count too: report them even if they look expired.

Vulnerabilities in third-party AI models or libraries should go to their maintainers. Do tell us if PulseForge uses them in an unsafe way.
